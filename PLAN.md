# 🌌 Fractal Visualizer
**Интерактивная визуализация фракталов (Мандельброта) с плавным zoom, drag-and-zoom и темной/светлой темой.**

## 📌 Статус
✅ **Готово к публикации**
- Рендеринг фрактала Мандельброта ✅
- Интерактивность: zoom, drag-and-zoom ✅
- Адаптивный UI для десктопа, лэптопа и мобильных ✅
- Тёмная/светлая тема с сохранением в localStorage ✅
- Плавные анимации (загрузка, переходы) ✅
- Оптимизация производительности ✅

## 🔧 Технические детали
### **Стек технологий**
- **HTML5 Canvas** для рендеринга фракталов
- **CSS3** для анимаций и адаптивности
- **JavaScript** для интерактивности
- **localStorage** для сохранения состояния

### **Функционал**
| Функция               | Описание                                                                 | Статус  |
|------------------------|---------------------------------------------------------------------------|---------|
| Рендеринг фрактала    | Алгоритм Мандельброта с настройкой итераций и цветовой схемы          | ✅ Готово |
| Zoom                   | Плавное масштабирование колесом мыши                                  | ✅ Готово |
| Drag-and-zoom          | Перетаскивание для панорамирования                                   | ✅ Готово |
| Темы                   | Переключение между тёмной и светлой темой с сохранением                 | ✅ Готово |
| Анимации               | Плавные переходы при загрузке и изменении параметров                   | ✅ Готово |
| Адаптивность           | Работа на десктопе, лэптопах и мобильных                               | ✅ Готово |

## 🎨 UI/UX
- **Анимации:**
  - Вращающийся лоадер при загрузке
  - Плавное появление фрактала после рендеринга
  - Обратная связь при взаимодействии с кнопками и слайдерами

- **Адаптивность:**
  - Оптимизация для всех размеров экранов (десктоп, лэптоп, мобильный)
  - Отступы и размеры элементов масштабируются

- **Тематизация:**
  - Тёмная тема по умолчанию
  - Светлая тема с сохранением выбора
