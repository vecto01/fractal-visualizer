# Fractal Visualizer

**Интерактивный генератор фракталов Мандельброта и Джулия с анимациями, пользовательскими палитрами и режимом "Кинетическая живопись".**

## 📌 Демонстрация

![Fractal Visualizer Demo](https://raw.githubusercontent.com/vecto01/fractal-visualizer/main/shots/fractal_demo.gif)

## 🔧 Функционал
- **Два типа фракталов**: Мандельброта и Джулия.
- **5+ пользовательских палитр**: Plasma, Night, Solar, Ultraviolet, Monochrome, Rainbow Gradient, Earth Tones.
- **Режим "Кинетическая живопись"**: Фрактал изменяется под воздействием звука в реальном времени.
- **Анимации**: Загрузка, обновление, экспорт и реакция на звук.
- **Адаптивный интерфейс**: Работает на всех устройствах (десктоп, планшет, мобильный).
- **Экспорт в PNG/GIF**: Сохраните любимый фрактал на устройство.

## 🎛 Режим "Кинетическая живопись"
В этом режиме фрактал изменяется под воздействием звука в реальном времени с использованием Web Audio API.

### **Функционал режима**
- **Синхронизация с аудио**: Фрактал адаптируется под частотный спектр звука.
- **Адаптивная скорость**: Скорость анимации изменяется в зависимости от типа устройства (десктоп/мобильный).
- **Параметры визуализации**:
  - **Zoom**: Зум фрактала изменяется в зависимости от громкости звука.
  - **Rotation**: Поворот фрактала синхронизируется с ритмом звука.
  - **Color Intensity**: Интенсивность цвета зависит от среднего значения частот.
  - **Opacity**: Прозрачность фрактала изменяется под воздействием звука.

### **Как пользоваться**
1. Включите режим "Кинетическая живопись" с помощью кнопки.
2. Подключите микрофон или воспроизведите музыку.
3. Наблюдайте, как фрактал "танцует" под звуковые волны.

### **Микровзаимодействия**
- **Анимация кнопки**: Пульсация и изменение цвета при наведении.
- **Адаптивные анимации**: Волновые эффекты на канвасе при наведении.
- **Синхронизация с `prefers-reduced-motion`**: Анимации автоматически отключаются для пользователей, предпочитающих минимизацию движений.

### **Технические детали**
- **Производительность**: Используется `requestAnimationFrame` для ограничения частоты обновлений до 60 FPS.
- **Оптимизация анимаций**:
  - Анимации волн и микровзаимодействия оптимизированы через `requestAnimationFrame`.
  - Добавлен дебаунс для обновления параметров фрактала на основе аудио.
  - Анимации канваса имеют `will-change: transform` для ускорения рендеринга.
- **Адаптивность**: Медиа-запросы корректируют параметры анимаций и отступы для всех устройств.
- **Синхронизация с аудио**: Используется Web Audio API для обработки частотного спектра звука.
- **Обработка ошибок**: Визуальная обратная связь при ошибках аудиопотока.

## 🛠 Установка

Просто откройте файл `index.html` в браузере — никаких зависимостей не требуется!

## 🎨 Как пользоваться
1. Выберите тип фрактала (Мандельброта или Джулия).
2. Выберите цветовую палитру.
3. Настройте количество итераций и уровень зума.
4. Нажмите "Обновить фрактал", чтобы увидеть результат.
5. Включите режим "Кинетическая живопись" и начните взаимодействовать со звуком.
6. Нажмите "Экспортировать", чтобы сохранить фрактал на устройство.

## 📱 Адаптивность
Интерфейс автоматически адаптируется под размер экрана с использованием медиа-запросов:
- **Десктоп (>1200px)**: Полноценный интерфейс с панелью управления, ускоренные анимации и увеличенные отступы.
- **Планшет (768-1200px)**: Оптимизированный вид для касаний, средние анимации и адаптивные отступы.
- **Мобильный (<768px)**: Удобное взаимодействие с полноэкранным отображением, замедленные анимации и минимальные отступы.

### **Параметры адаптивности**
- **Десктоп (>1200px)**: Ускоренные анимации, увеличенные отступы.
- **Планшет (768-1200px)**: Средние анимации, адаптивные отступы.
- **Мобильный (<768px)**: Замедленные анимации, минимальные отступы.

## 🎨 Палитры
- **Plasma**: Яркие цвета, напоминающие плазму.
- **Night**: Темная палитра для ночного просмотра.
- **Solar**: Солнечные оттенки.
- **Ultraviolet**: Фиолетовые и голубые тона.
- **Monochrome**: Черно-белый режим.
