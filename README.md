# Fractal Visualizer

**Интерактивный генератор фракталов Мандельброта и Джулия с анимациями, пользовательскими палитрами и режимом "Кинетическая живопись".**

## 📌 Демонстрация

![Fractal Visualizer Demo](https://raw.githubusercontent.com/vecto01/fractal-visualizer/main/shots/fractal_demo.gif)

## 🔧 Функционал
- **Два типа фракталов**: Мандельброта и Джулия.
- **5+ пользовательских палитр**: Plasma, Night, Solar, Ultraviolet, Monochrome, Rainbow Gradient, Earth Tones.
- **Режим "Кинетическая живопись"**: Фрактал изменяется под воздействием звука в реальном времени.
- **Анимации**: Загрузка, обновление, экспорт и реакция на звук.
- **Адаптивный интерфейс**: Работает на всех устройствах (десктоп, планшет, мобильный).
- **Экспорт в PNG/GIF**: Сохраните любимый фрактал на устройство.

## 🎛 Режим "Кинетическая живопись"

В этом режиме фрактал реагирует на звук в реальном времени:
- **Параметры**:
  - **Чувствительность к звуку**: Настройте, насколько сильно фрактал будет изменяться под воздействием звука.
  - **Скорость изменения**: Контролируйте, как быстро фрактал будет адаптироваться к звуку.
  - **Палитры**: Выберите одну из доступных палитр для визуализации.

- **Как пользоваться**:
  1. Включите режим "Кинетическая живопись" с помощью кнопки.
  2. Подключите микрофон или воспроизведите музыку.
  3. Наблюдайте, как фрактал "танцует" под ритм звука.

- **Микровзаимодействия**:
  - Анимация кнопки "Включить звук": Пульсация при наведении.
  - Визуальная обратная связь при изменении параметров: Плавное изменение цвета кнопок.

## 🛠 Установка

Просто откройте файл `index.html` в браузере — никаких зависимостей не требуется!

## 🎨 Как пользоваться
1. Выберите тип фрактала (Мандельброта или Джулия).
2. Выберите цветовую палитру.
3. Настройте количество итераций и уровень зума.
4. Нажмите "Обновить фрактал", чтобы увидеть результат.
5. Включите режим "Кинетическая живопись" и начните взаимодействовать со звуком.
6. Нажмите "Экспортировать", чтобы сохранить фрактал на устройство.

## 📱 Адаптивность
Интерфейс автоматически адаптируется под размер экрана:
- **Десктоп**: Полноценный интерфейс с панелью управления.
- **Планшет**: Оптимизированный вид для касаний.
- **Мобильный**: Удобное взаимодействие с полноэкранным отображением.

## 🎨 Палитры
- **Plasma**: Яркие цвета, напоминающие плазму.
- **Night**: Темная палитра для ночного просмотра.
- **Solar**: Солнечные оттенки.
- **Ultraviolet**: Фиолетовые и голубые тона.
- **Monochrome**: Черно-белый режим.
- **Rainbow Gradient**: Радужный градиент.
- **Earth Tones**: Натуральные земные цвета.

## 📦 Экспорт
Нажмите кнопку "Экспортировать", чтобы сохранить фрактал в формате PNG или анимированного GIF.

## 🔄 Обновления
- **Анимации**: Плавные переходы при обновлении фрактала, синхронизированные с Web Audio API.
- **Микроинтерактивности**: Пульсация кнопок при наведении, визуальная обратная связь при изменении параметров.
- **Анимация загрузки**: Вращающийся индикатор и пульсирующая кнопка "Start" во время рендеринга фрактала.
- **Плавное появление элементов**: Кнопки и сообщения появляются с анимацией после завершения загрузки.
- **Улучшенная адаптивность**: Интерфейс оптимизирован для всех устройств (десктоп, планшет, мобильный).
- **Футер**: Добавлен авторский блок внизу страницы.
- **Режим "Кинетическая живопись"**: Реакция фрактала на звук в реальном времени.
